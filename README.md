# Smart Pillbox — прототип планировщика

Умная таблетница 7 дней × 4 приёма: расписание по рецепту, проверки совместимости, раскладка по ячейкам. ИИ распознаёт текст рецепта, сверяет расписание и переводит сводки на кыргызский.

> Демо-справочник лекарств, не медицинская база. Не используйте реальные данные пациентов.

## Файлы

| Файл | Что это |
|---|---|
| `index.html` | Сам прототип |
| `api/ai.js` | Посредник: принимает запрос страницы и обращается к Claude API. Ключ хранится только здесь |
| `api/_sysprompt.js` | Системный промпт планировщика |
| `vercel.json` | Настройка времени ответа сервера |

## Публикация на Vercel (ИИ работает у всех)

1. Загрузите эти файлы в репозиторий GitHub.
2. Зайдите на vercel.com → **Sign up with GitHub**.
3. **Add New → Project** → выберите репозиторий → **Deploy**.
4. В console.anthropic.com создайте API-ключ и поставьте лимит расходов (**Settings → Limits**).
5. В Vercel: **Project → Settings → Environment Variables** → добавьте `ANTHROPIC_API_KEY` = ваш ключ.
6. **Deployments → ⋯ → Redeploy**. Ссылка вида `https://<имя>.vercel.app` откроется у всех.

### Необязательные настройки (Environment Variables)

| Переменная | По умолчанию | Зачем |
|---|---|---|
| `MODEL_FAST` | `claude-haiku-4-5` | Модель для распознавания и перевода |
| `MODEL_SMART` | `claude-sonnet-4-5` | Модель для сравнения с алгоритмом |
| `RATE_LIMIT` | `20` | Сколько запросов к ИИ можно сделать с одного IP за 10 минут |
| `ALLOWED_ORIGIN` | — | Адрес вашего сайта. С ним запросы с чужих сайтов отклоняются |

Если модель по умолчанию устарела, возьмите актуальное название на docs.claude.com → Models.

## Только GitHub Pages (без ИИ)

**Settings → Pages → Branch: main → Save.** Прототип будет работать, а кнопки ИИ скроются сами.
